# دستیار هوش مصنوعی گردش‌کار

اگر فرایندی را برای دستیار هوش مصنوعی شرح دهید، می‌تواند پیش‌نویس گردش‌کار آن را بسازد. همچنین می‌توانید از دستیار بخواهید پیشنهادش را تغییر دهد یا نموداری را که باز کرده‌اید توضیح دهد.

برای استفاده از دستیار، طرح و مجوزهای شما باید اجازهٔ استفاده از آن را بدهند، مدیر باید آن را فعال کرده باشد و مدلی در فضای کاری یا تنظیمات پیش‌فرض پلتفرم تعیین شده باشد.

## تنظیم هوش مصنوعی

مدیر مجاز می‌تواند از بخش **تنظیمات ← دستیار هوش مصنوعی** دستیار را فعال کند، مدل موردنظر یا مدل پیش‌فرض پلتفرم را انتخاب کند و تنظیمات لازم برای ارائه‌دهندهٔ آن مدل را وارد و ذخیره کند. اگر از Ollama روی سرور خودتان استفاده می‌کنید، باید آدرس پایهٔ آن را وارد کنید.

کلید API پس از ذخیره دوباره نمایش داده نمی‌شود. اگر نمی‌خواهید آن را تغییر دهید، فیلد کلید را خالی بگذارید. برای تنظیم پیش‌فرض پلتفرم، [مدیریت پلتفرم](./app-admin.md) را ببینید.

## ساخت پیش‌نویس گردش‌کار

1. یک پیش‌نویس گردش‌کار را در [طراح](./workflow-designer.md) باز کنید و به دستیار هوش مصنوعی بروید.
2. فرایند را توضیح دهید و **ساخت پیش‌نویس** را بزنید. پیش‌نویس روی بوم ظاهر می‌شود، اما هنوز ذخیره نشده است.
3. مرحله‌ها، مسئولان و مشکلات گزارش‌شده را بررسی کنید. اگر تغییری لازم است، **اصلاح** را بزنید؛ اگر نمی‌خواهید پیشنهاد را نگه دارید، **دور انداختن** را انتخاب کنید.
4. وقتی پیش‌نویس مناسب بود، آن را بپذیرید. سپس مانند هر گردش‌کار دیگری آن را اعتبارسنجی و منتشر کنید. پذیرفتن پیشنهاد به‌تنهایی آن را منتشر نمی‌کند.

برای اینکه دستیار نمودار فعلی را به زبان ساده توضیح دهد، **توضیح این گردش‌کار** را انتخاب کنید. پاسخ و پیش‌نویس دستیار را با دقت بررسی کنید؛ ممکن است فرایند را اشتباه فهمیده باشد. اعتبارسنجی طراح هم جای بررسی قواعد کاری و دسترسی‌ها را نمی‌گیرد.

اگر دستیار در دسترس نیست، از مدیر بخواهید طرح، فعال بودن دستیار، تنظیمات ارائه‌دهنده و مجوزهای شما را بررسی کند.
