# دستیار هوش مصنوعی گردش‌کار

دستیار هوش مصنوعی در طراح گردش‌کار می‌تواند از شرح یک فرایند پیش‌نویس بسازد، پیشنهاد را تغییر دهد یا نمودار فعلی را توضیح دهد. دسترسی به آن به طرح، مجوزها و تنظیمات فضای کاری بستگی دارد. مدیر باید آن را فعال کند و مدلی در فضای کاری یا در تنظیمات پیش‌فرض پلتفرم تعیین شده باشد.

## تنظیم هوش مصنوعی

مدیر مجاز از **تنظیمات ← دستیار هوش مصنوعی**، دستیار را فعال می‌کند، مدل یا پیش‌فرض پلتفرم را انتخاب می‌کند، تنظیمات لازم ارائه‌دهنده را وارد و ذخیره می‌کند. برای Ollama خودمیزبان، آدرس پایه لازم است. کلید API ذخیره‌شده دوباره نمایش داده نمی‌شود؛ برای حفظ آن، فیلد کلید را خالی بگذارید. برای تنظیم پیش‌فرض پلتفرم، [مدیریت پلتفرم](./app-admin.md) را ببینید.

## ساخت پیش‌نویس گردش‌کار

1. یک پیش‌نویس گردش‌کار را در [طراح](./workflow-designer.md) باز کنید و دستیار هوش مصنوعی را باز کنید.
2. فرایند را شرح دهید و **ساخت پیش‌نویس** را بزنید. نتیجه به‌صورت پیش‌نویس ذخیره‌نشده روی بوم ظاهر می‌شود.
3. مرحله‌ها، مسئولان و مشکلات گزارش‌شده را بررسی کنید. برای درخواست تغییر از **اصلاح** و برای حذف پیشنهاد از **دور انداختن** استفاده کنید.
4. وقتی پیش‌نویس مناسب بود، آن را بپذیرید. سپس از ابزارهای معمول گردش‌کار برای اعتبارسنجی و انتشار استفاده کنید؛ پذیرفتن، آن را منتشر نمی‌کند.

برای دریافت توضیح سادهٔ نمودار فعلی، **توضیح این گردش‌کار** را انتخاب کنید. نتیجه را با دقت بررسی کنید: دستیار ممکن است فرایند را اشتباه برداشت کند و اعتبارسنجی طراح جای بررسی قواعد کاری و دسترسی را نمی‌گیرد. اگر دستیار در دسترس نیست، طرح، فعال‌سازی، تنظیمات ارائه‌دهنده و دسترسی خود را با مدیر بررسی کنید.
