# Contributing to edubaco/docs

## License

Contributions are submitted under the **MIT License** ([LICENSE](LICENSE)).

## DCO sign-off

Every commit must carry: `Signed-off-by: Your Name <you@example.com>` (use `git commit -s`).

## Workflow

1. Fork, edit Markdown files in `docs/` or `i18n/<locale>/`.
2. Run `node check-parity.mjs` to check file parity.
3. Commit with `-s` and open a PR.
