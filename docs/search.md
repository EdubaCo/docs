# Global search

**Global search** lets you jump straight to work across your workspace without
navigating through menus. You can open it from any screen in Eduba.

## Opening the search palette

- Press **`Ctrl K`** (or **`Cmd K`** on macOS), or
- Select the **Search** button in the top bar.

Start typing to see live, grouped results with highlighted matching snippets.

## What global search covers

Results are grouped by entity type:

| Group | What matches |
| --- | --- |
| **Tasks** | Tasks by title, description, or context. |
| **Projects** | Projects by name, customer, or description. |
| **Documents** | Documents by name or path. |
| **Workflow definitions** | Workflow definitions by name or key. |

## Keyboard navigation and recent searches

- Use **Up** and **Down** arrow keys to move across all result groups.
- Press **Enter** to open the selected item.
- Press **Escape** (or click outside the dialog) to close the palette.
- When the search box is empty, your **Recent searches** appear so you can
  re-run a previous query with one click, or select **Clear** to remove your
  recent search history.

## Access filtering

Global search respects the [policy engine](./policy.md). You only see tasks,
projects, documents, and workflow definitions that your permissions allow you
to view — items you cannot access are never returned in results.
