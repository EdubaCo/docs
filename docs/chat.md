# Chat and task comments

The current app provides comments on individual tasks. The separate Chat module described in earlier documentation is not currently available as a chat screen; a plan listing alone does not make channels or direct messages available.

## Discuss a task

1. Open the task from [My Work](./my-work.md) or its project.
2. Open **Comments**, enter your message, and select **Add comment**.
3. Return to the task to read the discussion. If posting fails or the control is unavailable, check your access with a workspace administrator.

Avoid putting personal data in comments. Task comments stay with the task; they are not a substitute for a channel or direct message.
