# Roles and org chart

**Roles** are the unit Eduba grants capabilities to, and the **org chart** models
the reporting structure roles and routing can reference. A tenant ships with a
set of system roles; admins create custom roles for their organization and assign
them to users — directly or through [user groups](./groups.md).

:::info Permission
Managing roles and the org chart is a tenant-admin task and requires the
**`manageUsers`** capability.
:::
